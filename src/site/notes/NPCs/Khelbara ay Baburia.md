# Khelbara ay Baburia

![Khelbara.jpg](/img/user/NPCs/Attachment/Khelbara.jpg)


## Erscheinung

Eine schwarzhaarige Mittelländerin. Das auffälligste Merkmal ist die Tätowierung einer Smaragdnatter, die sich vom Gesicht bis zum Bauchnabel hinunterschlängelt. Sie trägt leichte Gewänder, die ihre Figur betonen; unterwegs hüllt sie sich in einen Kapuzenmantel.


## Zitate

> "Also früher, als die Mhoguli herrschte, waren solche Bedenken kein großes Problem - aber wir können uns gerne an die neuen Gepflogenheiten anpassen."
> "Glaube mir, niemand schätzt ein Leben höher ein als ich."
> "Es wäre so nett von dir, wenn du mir dabei helfen könntest." (dabei verführerisch, aber auch leicht spöttisch blickend.)
